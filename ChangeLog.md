# Changelog — Theme Switcher Lite

All notable changes to this module are documented here.
This project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-07-24
### Added
- Accent-colour picker in the top-right menu, with an admin-defined palette.
- One-click light / dark mode, reusing Dolibarr's native dark palette.
- Per-user preference stored in the browser (localStorage), applied on every page with no flash.
- Setup page: palette editor with live preview, default accent, allow dark mode, start in dark mode.
- Five languages: English, French, German, Spanish, Italian.
- No database table, no data entry, no performance impact.
